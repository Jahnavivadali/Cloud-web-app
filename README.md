
#  **CLOUD WEB APPLICATION (LINUX + GIT PROJECT)**
---

#  **OBJECTIVE**

This project demonstrates foundational DevOps skills including Linux scripting, Git/GitHub workflows, and basic web development.

It is designed to simulate real-world project structure and version control practices.

---

#  **TECHNOLOGIES USED**

* **Frontend:** HTML5
* **Scripting:** Bash (Linux Shell Scripting)
* **Version Control:** Git & GitHub
* **Environment:** Linux Terminal / Windows CMD (Git Bash)

# **HOW TO RUN THE PROJECT**

---

#  **1. RUN WEB APPLICATION**

Open the HTML file in a browser:

```bash
app/index.html
```

OR Linux/macOS:

```bash
xdg-open app/index.html
```

---

#     2. RUN SHELL SCRIPT**

Run the project status script:

```bash
bash scripts/project-status.sh add project updates here
```
